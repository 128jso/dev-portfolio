## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/128jso/dev-portfolio.git
cd dev-portfolio
```

### 2. Install Dependencies & Launch
```bash
npm install
npm run dev
```

Open **`http://localhost:3001`** in your browser to explore the portfolio!
